A match is a useful fact.
A matching hash and size mean the selected bytes match the baseline entry. Names identify files; renamed files appear as missing and new. Metadata and permissions are not hashed.
A checksum is not a signature.
A manifest can be modified. Use a trusted baseline. This tool does not prove authorship, verify signatures, scan for malware, or certify that a file is safe.
